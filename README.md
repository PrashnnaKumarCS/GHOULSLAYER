# GHOULSLAYER
> **RISE. FIGHT. SURVIVE.**

GHOULSLAYER is a 2D top-down zombie survival shooter built from scratch with C++17 and SFML 2.6.1.

## Overview
- **Language**: C++17
- **Graphics/Audio/Windowing**: SFML 2.6.1 (static build via CMake FetchContent)
- **Target Platform**: Windows (MinGW-w64 / MSVC)
- **Build System**: CMake 3.21+
